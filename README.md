# Фараоны Древнего Египта — интерактивная лента времени

Учебная страница для школьников 5-го класса: вертикальный таймлайн фараонов, пирамид, храмов и открытий археологов.

- Сортировка «от древних к поздним» и обратно, фильтры по типу и эпохе, поиск.
- 30 историй-приключений из жизни фараонов с пометкой «документ / сказка / легенда / находка» (файл `stories.js`).
- Раскрывающиеся карточки: кто это, какое было время, достижения, события, интересный факт.
- Ссылки на Google Earth и Google Maps (спутник), 3D-туры и проверенные источники.

- **Сад знаний** (`learn.html`): 46 карточек-вопросов с интервальными повторениями (система Лейтнера). Правильный ответ растит растение 🌱→🌿→🪴→🌳→🌴, ошибка возвращает к ростку. Прогресс хранится в браузере (localStorage).

- **Поговори с фараоном** (https://class.zenrepublic.agency/, нужен логин): чат с любым из 21 фараона — отвечает в роли и только про Древний Египет. Ссылка — в шапке ленты времени и сада знаний.

**Открыть:** https://yuri-parfentcov.github.io/pharaohs-timeline/

Хронология — по I. Shaw, *The Oxford History of Ancient Egypt*; уточнения — Bronk Ramsey et al., *Science* 2010.
Данные лежат в `data.js` — чтобы добавить фараона, допишите объект в массив `ITEMS`.
